0. 主线一句话#

Task3 的三讲在回答同一个问题的三个尺度：「模型能学到什么，取决于你在看到数据之前替它决定了什么。」

  • 01 讲定的是「参数怎么被调」：一组参数、一个 loss、一条梯度、一次划分。
  • 02 讲定的是「结构怎么被选」：数据表示保留哪条关系，架构就把哪条关系写进连接。
  • 05 讲定的是「它站在流程的哪一格」：插入点越靠近理论，保留的中间量越多，可解释性越强。

三讲的连接词是「归纳偏置」：01 给出定义（数据之外的默认偏好），02 给出操作（表示 + 结构 + 损失），05 把它推到流程尺度（插入点 = 你决定保留多少机理）。

反过来读也成立：一个漂亮的 R² 之所以不能直接采信，正因为它同时缺这三层——没说是哪个集合上的（01）、没说任务定义对不对（02）、没说是替代还是加速（05）。

2. 01 讲：学习的本质是一组参数#

2.1 先把现实变成模型能比较的数字（01-P09、P10）#

课件用一张房价表引入（01-P09），三个术语要分清：

术语 定义 房价例子里是什么
Sample 样本 一行 = 一个完整研究对象 一套房
Feature 特征 描述对象的信息 面积、楼层、朝向、房龄、距地铁
Label 标签 模型希望回答的结果 成交价

课件特意标注：这是抽象案例，在生物、化学、材料领域可以有不同的变体。

数据处理六步（01-P10），每一步配一个真实问题：

步 动作 配套问题
1 原始表格，认样本与字段 一行到底代表什么？
2 检查缺失 / 异常并记录 朝向缺失怎么办？
3 去重 / 统一单位 重复记录会不会被误以为更重要？
4 类别编码 南和南北怎样编码？
5 缩放数值 面积和楼层能直接比吗？
6 输入矩阵 X 交给模型

2.2 三集划分：学习之前先留出没看过的房子（01-P10）#

集合 比喻 用途 纪律
训练集 练习题 调整参数，可以反复查看 参数在这里学
验证集 模拟考试 选结构和设置 超参在这里选
测试集 期末考试 方案确定后的最后一次评价 不能边看边改模型

课件原话两条：训练集不是全部数据；测试集不能边看边改模型。 以及那条最容易被违反的原则：数据处理规则从训练数据确定，再应用到验证集和测试集（缩放参数、填充值、编码表都只能在训练集上拟合）。

2.3 模型 = 一组可调参数（01-P11、P12）#

线性回归就是给点集找一条直线：ŷ = wx + b。w 控制斜率（线旋转），b 控制截距（线上下移动）。训练前机器不知道哪组 (w,b) 最好。

课件给的定义是全讲的地基：一个模型，就是一组可以调节的参数；训练和「学习」就是从所有参数中选出最优的一组参数（01-P12）。线性回归是两个参数，Qwen3-8B 是 80 亿个（01-P18）——同一个定义。

2.4 最优 = 把很多个错压成一个数（01-P13、P14）#

每个样本都有一条垂直的误差线，叫残差 eᵢ = yᵢ − ŷᵢ。一条线会产生很多个残差，损失函数回答的是：怎样把「很多个错」压成一个数字，告诉机器这条线到底好不好？

MSE（均方误差）：L(w,b) = (1/n)Σᵢ(yᵢ − ŷᵢ)²。平方让大错罚得更重，均值让样本数不影响量级（01-P13）。

三条候选线的对比（01-P14）：MSE = 10.60 / 1.29 / 0.12。MSE 越小 → 拟合误差越小 → 这组参数越好。

2.5 训练 = 在 loss landscape 上往低处走（01-P15~P17）#

换个视角：每一组 (w,b) 对应一条线，也对应一个 loss。于是「选直线」变成「在参数空间的地形上找最低点」（01-P15）。梯度告诉你「哪边上升最快」，取反方向就能让 loss 下降：

θ ← θ − η·∇L(θ)        新参数 = 旧参数 − 学习率 × 梯度

学习率 η 三档（01-P17）：

η 表现 后果
太小 稳定，但要走很多步 慢
合适 较快接近最低点 收敛
太大 震荡，甚至发散 失败

课件的总结：「学习」不仅取决于模型和数据，也取决于优化过程本身。

2.6 一个闭环（01-P18）#

数据 (x,y) → 模型 f → 预测 ŷ → Loss「错多少？」→ 梯度 → 更新参数 → 更好的模型
                ↑___________________________________________|

训练就是反复执行这个闭环。对线性回归是两个参数，对 LLM 是几百亿个，骨架不变。

3. 01 讲：从直线到深网（01-P19~P22）#

线性模型不够用的三个理由（01-P19）：

现象 例子 直线为什么不行
非线性 房龄 0→5 与 30→35 的影响不同 斜率恒定
交互 同样 10 ㎡，地段不同增量不同 只做加法
阈值 距地铁影响在某个距离后突变 画不出台阶

结论：非线性 + 交互 + 阈值 → 需要更有表达力的结构 → 多层神经网络。 世界不总是「简单相加」。

MLP 的结构（01-P20、P21）：输入特征 → 隐藏层 1 → 隐藏层 2 → 输出。深度、宽度、连接方式决定表达能力，也带来参数成本；「特征之间怎样组合」从人的工作变成了训练问题。手写数字识别是最小例子：输入一张图，输出一个数字。

三者的对比（01-P22）：

线性回归 浅层神经网络 深层神经网络
形式 ŷ = wᵀx + b F(x) = w₂ᵀσ(w₁ᵀx + b₁) + b₂ F(x) = w₃ᵀσ(w₂ᵀσ(w₁ᵀx+b₁)+b₂)+b₃
参数 2 个 少量 几十亿个
骨架 参数化模型 → Loss → 梯度 → 更新 同左 同左

复杂度增加几个数量级，骨架一步没变。 这是 01 讲最省力的记忆点。

4. 01 讲：归纳偏置与模型族（01-P23~P25）#

4.1 定义（01-P23）#

只见过少量样本时，许多不同规律都能解释已知数据；模型必须依赖某种默认偏好去回答未见输入。课件摆了三条都「合理」的延伸：偏好直线（已知点外按相近斜率延伸）、偏好平滑（允许弯曲但相邻位置连续）、允许突变（边界前后规律可突变）。

归纳偏置 = 数据之外的默认偏好，它决定模型更容易学到哪一种解释。

4.2 先验怎样变成偏置（01-P24）#

先验（科学知识：规律与不变量）
  → 表示（数据表示：网格 / 序列 / 图）
  → 约束（结构 / Loss：共享 / 对称 / 守恒）
  → 偏好（归纳偏置：更容易学什么）
  → 验证（未见样本：是否真的泛化）

三个课件给的先验例子：相邻像素通常更相关；原子编号不应改变分子性质；守恒量应满足方程。

关键句：先验不会自动生效——写进数据表示、网络结构、Loss 或数据增强后，才成为归纳偏置。

4.3 模型族对照（01-P25）#

模型族 默认假设 写进系统的方式
线性回归 关系近似线性、可加 线性函数
MLP 固定长度向量；特征可全局交互 全连接 + 非线性
CNN 局部模式可复用；卷积层平移等变 局部感受野 + 权重共享
RNN / LSTM 顺序重要；状态转移规则沿时间复用 递归状态 + 时间共享
GNN 连接关系重要；节点编号不重要 消息传递 + 对称聚合
等变网络 旋转/平移时输出按规律变化 等变表示
Transformer token 两两交互；顺序由位置注入 注意力 + 位置编码

右侧的「价格标签」：先验越强 → 需要的数据越少，但先验错了就全错；先验越弱 → 越灵活，但所需数据量指数上升。多数科学问题落在 N = 10² ~ 10⁴。 课件自己注明这是概念示意，不是严格排行榜——关键是先验是否匹配任务。

5. 01 讲：一个 Agent 时代的真实案例（01-P07）#

Prompt：「请你搭建一个 GNN，帮我拟合 @data/ 下的分子数据」。Agent 交回三项打勾：

打勾项 证明力 缺什么
代码能跑 工程链路通了 不证明科学问题对
R² = 0.94 某个集合上的拟合程度 没说是哪个集合；没和 baseline 比
图很好看 散点贴着对角线 画的就是参与拟合的点

三个追问：这三项里有几项是真的？GNN 是什么网络？为什么选择 GNN？

结论（01-P07）：Agent 时代，代码应该是在知道原理的情况下全权交给 Agent。 02 讲把同一案例诊断为「信息不足；还没理解数据，就先指定了模型」（02-P02）。

6. 02 讲：架构的本质是「谁和谁交换信息」（02-P05）#

同一份数据，换一种连接方式，模型就会相信不同的关系。 课件给了一个可复用的三问：

  1. 输入单元是什么？
  2. 连接由谁定义？
  3. 权重在哪里共享？
架构 输入单元 怎样交流 含义
MLP 全部特征 全连接 弱结构先验
CNN 局部网格 共享卷积核 局部性 + 平移共享
RNN 前后位置 循环状态 顺序 + 因果
Transformer 任意 token 注意力权重 数据依赖的全局连接
GNN 相邻节点 沿边聚合 显式拓扑 + 置换不变

7. 02 讲：五个家族的动机（02-P08~P20）#

家族 为什么出现（课件动机） 关键机制 一句话判据
CNN 拍平丢邻域，且第一层参数量随像素数膨胀（1024×1024 接 4096 隐单元 ≈ 4.3×10⁹） 局部连接 + 权重共享；感受野随深度扩大 空间坐标、局部邻域、多尺度是否有意义
RNN / LSTM 序列的核心是元素有顺序，当前判断依赖过去 状态沿时间传递；门控（遗忘/输入/输出、更新/重置）解决梯度链过长 顺序与因果是不是真的
Seq2Seq + Attention 固定长度 context 装不下整段输入 每步重新选择上下文；Q/K/V + multi-head 长输入的「该听谁」是否随位置变
Transformer 长距离依赖从链式传播改成内容相关的全局连接，同时训练可并行 自注意力 + FFN + 残差/归一化；因果掩码 token 之间是否需要两两交互
GNN 对象之间的关系本身就是数据的一部分 message → aggregate → update；节点/边/整图预测 不沿边的对象是否应当隔离
PINN 物理约束可以写进训练目标 L = L_data + λ·L_PDE + μ·L_boundary 有没有可微、可信的方程

三条提醒：

  • 注意力公式 Attention(Q,K,V) = softmax(QKᵀ/√d_k)V：Q 是「我在找什么」，K 是「我如何被匹配」，V 是「被选中后贡献什么」（02-P15）。
  • Transformer 的「全局」不是平均混合，而是由内容决定的加权连接（02-P15）。
  • PINN 的选择依据是「有可微、可信的物理约束」，不是数据看起来像图或像序列；没有可靠方程时，先验可能变成错误约束（02-P20）。

8. 02 讲：六类数据与三问（02-P23~P29）#

数据类型 形状 必须保留什么 一个样本是什么 怎样划分
表格 / 矩阵 N × d 行列语义、单位、稀疏性、批次、缺失 一株植物还是一次测量 重复测量与同源不能跨集

每类的判决句（课件原话的转述）：

  • 表格：矩阵形状相同，不代表科学含义相同（02-P24）。
  • 图像：关键不是「长得像图片」，而是空间坐标、局部邻域与多尺度是否有意义（02-P25）。
  • 序列：不能只看长度 L；token 的含义、顺序与采样机制共同决定表示（02-P26）。
  • 图：图不是天然真理；邻居怎么连、边表示什么，本身就是需要领域确认的假设（02-P27）。
  • 3D：核心是对称性；标量常要求不变，方向量可能需要等变（02-P28）。
  • 时空：至少两种结构；验证必须同时回答「新时间」和「新地点」（02-P29）。

10. 02 讲：模型选型六问（02-P03、P32~P38）#

先说流程（02-P32）：不要让 Agent 直接写训练代码；先完成六问得到建模需求说明书，再进入「候选 → 训练 → 验证 → 诊断 → 再选择」的循环，最终交付报告、代码、不确定性与复现实验。

问 写进 Prompt 的内容 决定模型选型的哪些方面 常见错误
Q1 目标 目标变量、科学用途、回归/分类/排序/生成/聚类/异常检测 输出层、损失函数、指标；标签构造与成功的科学含义 把「筛选优先级」当「数值回归」做

Q5 先验 对称性、守恒量、单调性、局域性、周期边界、机理方程、已知不可行区域 是否等变、约束损失、机理耦合；数据效率与外推可信度 明知旋转/置换规律，却让 MLP 重新猜
Q6 交付 可解释性、不确定性、推理成本、内插/外推、部署延迟、失败报警 黑箱能否接受；是否需要 GP/集成/校准；验证集模拟哪种场景 需要机理解释时只交付黑箱分数

每问的金句（我的摘录）：

  • Q1：任务不是数据集自带的标签名，而是你准备怎样使用答案。
  • Q2：不先定义科学独立性，再统计 N；否则漂亮指标可能只是同源泄漏。
  • Q3：数据模态不是文件格式；真正重要的是内部关系怎样进入计算。
  • Q4：样本少时，正确先验与可靠验证通常比增加参数更值钱。
  • Q5：科学家相对纯 AI 工程师的优势，不只是数据，而是知道哪些规律绝不该被违反。
  • Q6：模型选型的终点不是排行榜第一，而是得到一个在目标场景中可用、可信的答案。

11.1 一份填写好的任务书（02-P32 右侧示例）#

课件在「六问」旁边放了一份真实示例：高熵合金组分 → 析氢过电位，从 5000 个候选里挑 20 个做实验。它把六问落到了可执行的程度：

栏目 示例内容
科学目标 从合金组分预测析氢反应过电位，用于从 5000 个候选组分中挑 20 个做实验
任务类型 回归，但真实用途是排序（Top-20 命中率优先于 RMSE）
一个样本 一条「组分配比 + 制备条件」记录；同一组分的重复实验属于同一组
数据结构 定长表格，13 维数值特征，无空间/时序/图结构 → 不需要 CNN / RNN / GNN
数据 data/hea.csv，N = 312；标签来自实验，重复性误差约 ±15 mV
先验 组分之和为 1（约束）；无旋转对称性问题
划分 按「组分族」分组划分（同族不得跨集合），5 折交叉验证，报告 mean±std
baseline ① 全局均值 ② 岭回归 ③ XGBoost ④ TabPFN
指标 主指标 Spearman ρ 与 Top-20 EF；辅助报 RMSE(mV)，并与 ±15 mV 实验误差对比
交付 指标对照表 + 误差分析 + 特征重要性 + 明确说明结论属内插还是外推
禁止 不得使用随机划分；不得在全量数据上做标准化或特征选择

这张表值得当成模板：它把「目标—样本—结构—先验—划分—baseline—指标—交付—禁止」写在同一页里，任何一项被改动，其他项都要跟着改。尤其是最后两条「禁止」，其实是 01-P10 那条纪律的工程写法——规则只能从训练集拟合，划分必须尊重科学独立性。

我的批注：这份示例最容易被忽略的是「辅助 RMSE 与 ±15 mV 实验误差对比」这一句。它给出了判断模型是否「够用」的天然标尺：如果模型的 RMSE 已经小于实验重复性误差，再往下压精度对科学决策没有增量。

02-P41 的课堂实训是「5 分钟把自己的数据写成建模任务书」，汇报只说三句话：

  1. 我的数据最像 __，必须保留 ____。
  2. 我的最小 baseline 是 __；第一候选模型族是 ____。
  3. 验证必须按 __ 切分；若 ____，我才升级模型。

我的批注：第三句里的「若…才升级」是这套方法最有用的部分。它把「换更大的模型」从直觉决策变成了带条件的决策，先写清楚升级的触发条件，就不会一上来就上大模型。

12. 05 讲：可解释性缺口（05-P02~P10）#

12.1 起点：科学是什么（05-P02~P05）#

  • 庞加莱：科学是由恒常关系构成的体系。
  • 爱因斯坦：科学的目的，是用尽可能少的基本概念和关系，理解全部感觉经验之间的联系。
  • 苹果落地与月球绕地是同一套关系（万有引力）；但知道方程不等于算得出结果（Navier–Stokes），困难来自计算代价。

于是 AI 的位置是「替代求解」，不是「替代理论」。05-P05 用 CFD 画了原型：

传统 CFD AI 结果代理
流程 几何与网格 → 控制方程 → 离散化 → 迭代求解 → 场 → 后处理 输入 X → 网络 → 输出 Y
代价 高，耗时长 低，速度快
保留 每一步都有物理含义 隐式学习物理规律与耦合
风险 算不动 机制缺失

12.2 AlphaFold2：预测成功，机理未定（05-P07~P09）#

AF2 从序列位置信息得到蛋白质三维结构（05-P8）；按 01-P6 的介绍，它在 CASP14 上预测精度达原子级，被认为是解决了困扰生物学界 50 年的「蛋白质折叠问题」。

但 2017 年诺贝尔化学奖得主 Richard Henderson 在 Science 的评论里说：

"solving the protein-folding problem means making accurate predictions of structures from amino acid sequences starting from first principles based on the underlying physics and chemistry."

课件在「预测结构」周围标了四个问号：折叠机制？化学精度？动态构象？实验验证？结论：科学机理的可解释性，依旧未确定。

问题于是变成（05-P10、P11）：能否让模型既有 AI 的效率，又有理论的可解释性？AI 在科研流程的哪些部分可以嵌入？如何嵌入？

13. 05 讲：拆解 DFT 计算流程（05-P12、P13）#

课件先列三种计算化学方法（05-P12）：

方法 基本变量 特点
DFT 电子密度 避免直接处理多电子波函数，成本较低，精度受泛函近似限制
Hartree–Fock 多电子波函数（Slater 行列式） 变分求近似基态
分子动力学 原子坐标与速度 经典力学近似，数值积分牛顿方程

然后把 DFT 完全展开成 7 个节点（05-P13）：

# 节点 做什么 备注
1 体系与计算参数 原子坐标、电荷、自旋、泛函、积分网格、收敛阈值 分子或周期体系
2 初始电子密度 原子密度叠加，或读已有电子态 作为 SCF 初猜
3 构建 Kohn–Sham 矩阵 T、V^ne、J、V^xc 四项积分 固定几何时 T、V^ne 不变；J、V^xc 随密度更新
4 求解 KS 方程 H^KS C = S C ε，得轨道系数与轨道能 反复求解耗时
5 更新电子密度 按电子数与自旋占据，再做密度混合 生成下一轮输入
6 电子自洽检查 计算总能量，看 ΔE、Δρ 与残差 未达阈值则回 3
7 结构优化与性质 几何优化（可选）、振动频率、电荷分布、DOS 更新坐标回 1，或输出性质

两个循环：内圈 SCF（3→4→5→6→3），外圈几何优化（7→1→…）。理解这张图的关键，是知道哪些量在循环内变、哪些不变（固定几何时 T 与 V^ne 不变，J 与 V^xc 随密度更新）。

14. 05 讲：七个插入点（05-P14~P21）#

标记 插入点 这一格的难处 AI 能做什么
A 初始电子分布 起点猜得不够好 提供更好的初值
B 构建矩阵 每轮计算量大 直接预测矩阵
C 求解方程 反复求解耗时 改进求解方法
D 交换关联部分 近似带来误差 学习更准确的泛函
E 能量结果 与高精度结果有差距 学习能量修正量
F 自洽循环 反复更新，可能难收敛 学习电子分布的更新
G 从结构到性质 整条流程成本高 直接预测能量和性质

我把它们按「保留多少机理」重新排成梯子（我的整理）：

保留机理多  A 初值 → C 求解 → B 矩阵 → D 泛函 → E 修正 → F 密度更新 → G 全替代  保留机理少
            加速器 ←──────────────────────────────────────────→ 替代品
  • 越靠左，越像加速器：理论没变，结果可解释，风险主要在精度与稳定性。
  • 越靠右，越像替代品：速度快，但机制缺失、外推风险大。
  • 可解释性不是模型的属性，而是插入点位置的函数。

15. 05 讲：四个代表工作（05-P22~P28）#

工作 主要目的 落在哪一格 模型方法 页码
SchNOrb 预测哈密顿量矩阵与重叠矩阵，获得分子轨道信息，加速自洽计算 B（构建矩阵） 基于 SchNet 的消息传递 GNN 05-P22
NeuralXC 学基准 DFT 的能量泛函修正，提高精度并提供势修正 D/E（泛函/能量修正） Behler–Parrinello 型原子网络（MLP） 05-P23、P24

核对提示（我的批注）：05-P28 的表格用「A：SchNOrb / E：NeuralXC / G：NequIP」标注，但按 05-P14 的定义，SchNOrb 实际落在 B（构建矩阵），NeuralXC 落在 D/E（泛函/能量修正），NequIP 落在 G。字母与位置不完全一致，读的时候以「它替换了流程里的哪一格」为准。

15.1 NeuralXC 的 Δ 学习（05-P23、P24）#

分子 → PBE（便宜、精度受限）→ E_PBE ┐
     → CCSD(T)（昂贵、准确）  → E_ref ┴→ ΔE_ref = E_ref − E_PBE  ← 网络只学这个差

网络不学「能量是多少」，只学「便宜方法和贵方法差多少」。差值通常更小、更平滑，同样数据量能学得更准。

我的批注：这与 01-P13 的「残差」是同一个东西的两种用法——在 01 里残差是 loss 的原料，在 05 里残差成了学习目标。从「预测答案」改成「预测答案与已知解的差」，是 AI4S 里性价比最高的做法：已知的先验留在模型外面，网络只补那一小块。

16. 05 讲：方法论四步与天平原型（05-P29~P34）#

16.1 四步方法论（05-P29）#

  1. 传统科学计算流程完全展开。
  2. 对每一个任务节点做界定，判断完成什么任务。
  3. 猜想哪些环节适合使用 AI 进行替代和优化；整个流程有没有可能被 AI 优化。
  4. 试验和验证。

16.2 过程建模 vs 结果建模（05-P30）#

过程建模 结果建模
形态 规律 → 中间状态 → 结果 输入 → 模型 → 输出
优点 可解释、可检查 快、便宜
代价 计算昂贵、难以健全 机制缺失、外推风险
典型 DFT、MD、CFD 求解 代理模型、全流程替代

课件的话：现代科学模型的发展，本质上是在可解释的过程与高效的结果预测之间寻找平衡；如何解决这个二元矛盾，可以成为一个值得研究的方向。

16.3 三个例子：天平的三个位置#

Pitzer 模型（05-P32）靠左：溶液自由能修正 ≈ 长程静电项 + B c² + C c³。第一项是确定已知项（整体电荷环境），第二、三项是展开项（两两相互作用、三体共同影响）。

多层模型展开法（05-P33）也靠左：用展开逼近难以计算的形式，课件自己标注「适用范围尚未确认」。

全流程替代（05-P34）站在最右端：网络直接从分子坐标给能量，利用函数拟合能力给出可能表示局部与全局的形状。

我的批注：前两个例子的共同点是「把已知项固定，只让模型补未知项」——可解释性不是靠事后解释黑箱，而是靠把模型限制在已知项之外的那一小块，这与 NeuralXC 的 Δ 学习同构。第三个例子则给出这条原则的价格：把整条链换掉，换来速度，失去机制。

靠什么检查 独立测试集 六问 + 表示说明书 中间量能否被独立检验
错了的表现 过拟合/泄漏/不收敛 指标漂亮但科学无用 准确但无法解释
一句话 参数选得对不对 任务定义得对不对 该不该用 AI 替这一格

我把它读成一句：先验在三讲里逐步「外移」——01 在 loss 与正则里，02 在网络连接与数据表示里，05 在流程结构与已知项里。位置越外，能约束的东西越多，也越需要领域知识。

19. 预测 vs 机理解释：三个判据（我的整理）#

判据 问题 不满足时的典型症状
1 预测 指标是否来自一个从未参与任何选择的集合？ 训练集 R²、边看边调的测试集
2 定义 指标对应的是科学上真正要用的那件事吗？ 把筛选做成回归、只看 RMSE 不看 Top-K
3 机理 模型的中间量能否被独立测量或独立计算检验？ 只能给出「特征重要性」这类事后归因

AF2 是判据 1 基本成立、判据 2 也说得通、判据 3 仍悬着的例子（05-P09）。两件事要分开评：模型准，不等于我们理解了；我们理解了，也不保证某个具体模型准。

对「可解释模型设计」的启示：想让判据 3 成立，最稳的办法不是给黑箱配一个解释器，而是把插入点选得足够靠左（A–D），让中间量本来就是理论里有的量（矩阵、泛函、密度）。

22. 我提炼的十条（用自己的话）#

  1. 训练就是选参数；loss 是「什么算好」的数学化，选错 loss 等于选错任务。
  2. 三集划分是评估的地基：测试集一旦被看过，就不再是测试集。
  3. 数据处理规则只能从训练集拟合，否则指标是自欺。
  4. 先验不会自动生效：不写进表示、结构或 loss，等于没有。
  5. 先验越强数据越省，先验错了全错；科学问题的 N 常在 10²~10⁴，选对先验比堆参数值钱。
  6. 架构的本质是信息通路：输入单元、连接定义者、权重共享处，三问定生死。
  7. 数据表示是关系取舍，不是格式转换；拍平就是把先验丢掉。
  8. 六问的顺序是收紧的：目标 → 样本 → 表示 → 规模 → 先验 → 交付；Q2 必须在 Q4 之前。
  9. AI4S 的插入点是一条可解释性梯子：越靠左越像加速器，越靠右越像替代品。
  10. 准确不等于理解：预测、任务定义、机理三层要分别评价，AF2 是最清楚的例子。

23. 自测（先答，再对要点）#

# 问题 要点
1 一个模型「学」到的是什么？ 一组参数；线性回归 2 个，LLM 几十亿个（01-P12、P18）
2 损失函数解决什么问题？ 把很多个残差压成一个可比较的数字（01-P13）
3 梯度下降的一句话公式？ θ ← θ − η·∇L(θ)；梯度指上升最快方向（01-P16）
4 学习率三档各是什么现象？ 太小慢、合适收敛、太大震荡发散（01-P17）
5 训练/验证/测试各用来做什么？ 调参 / 选结构与设置 / 最后评价（01-P10）
6 数据处理规则的拟合边界？ 只在训练集上拟合，再应用到验证/测试（01-P10）
7 归纳偏置的定义？ 数据之外的默认偏好，模型在见数据前就相信的东西（01-P23）
8 先验怎样才生效？ 写进数据表示、网络结构、Loss 或数据增强（01-P24）
9 先验强度与数据量的关系？ 强先验省数据但错了全错；弱先验灵活但数据量指数上升（01-P25）
10 读新架构的三问？ 输入单元？连接由谁定义？权重在哪共享？（02-P05）
11 CNN 的两个关键先验？ 局部连接 + 权重共享（02-P08）
12 Attention 解决了什么瓶颈？ 固定长度 context 装不下长输入（02-P14）
13 PINN 的关键变化在哪？ 不在连接，在 loss：加 PDE 与边界残差（02-P20）
14 六类科学数据？ 表格、图像/网格、序列/光谱、图、3D/点云、时空场（02-P23）
15 表示说明书五栏？ 样本单位、数据结构、必须保留、对称与变换、标签与质量（02-P30）
16 六问的顺序与理由？ 目标→样本→模态→规模→先验→交付；Q2 先于 Q4 因为独立性决定有效 N（02-P32~P38）
17 Q1 的典型错误？ 把筛选（排序）当预测（回归）（02-P33）
18 Q6 的典型错误？ 需要机理解释时只交付黑箱分数（02-P38）
19 DFT 的两个循环？ 内圈 SCF，外圈几何优化（05-P13）
20 七个插入点？ A 初值、B 矩阵、C 求解、D 泛函、E 能量修正、F 密度更新、G 结构→性质（05-P14）
21 NeuralXC 学的是什么？ ΔE = E_ref − E_PBE，两种方法的能量差（05-P23）
22 过程建模与结果建模的取舍？ 可解释/昂贵 vs 快速/机制缺失（05-P30）
23 为什么 AF2 是「准确≠理解」的例子？ 结构预测原子级准确，但折叠机制仍未被 first principles 解释（05-P9）
24 Pitzer 模型的可解释性来自哪里？ 第一项已知固定，只让展开项（2 体、3 体）待定（05-P32）
